This site uses no cookies and stores nothing in your browser.

It is hosted by Cloudflare, and Cloudflare Web Analytics counts visits. On each page a small script sends Cloudflare the page's address, the site you came from, your browser type and how fast the page loaded. Cloudflare also sees your IP address, as any host does. I see only totals (visits, popular pages, countries), never who you are. The data is shared with no one except Cloudflare, and never sold.

To opt out, block scripts or use a content blocker: the site works without scripts (the game clips then wait for you to press Play).
